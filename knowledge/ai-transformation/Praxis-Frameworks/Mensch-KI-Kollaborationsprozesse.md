# Mensch-KI-Kollaborationsprozesse

> Klare Rollenverteilung: Wer macht was in der Zusammenarbeit mit KI?

---

## Kernaussage

Die effektivsten KI-Prozesse definieren explizit, wie Mensch und KI zusammenarbeiten – wer den ersten Entwurf macht, wer Entscheidungen trifft, wie Übergaben funktionieren. Ohne diese Klarheit entstehen Reibungsverluste und Qualitätsprobleme.

---

## Paradigmenwechsel

| Alte Denkweise                         | Neue Denkweise                                       |
| -------------------------------------- | ---------------------------------------------------- |
| KI als Tool (ich nutze es manchmal)    | KI als Kollaborationspartner (wir arbeiten zusammen) |
| Entweder Mensch oder Maschine          | Orchestrierte Zusammenarbeit                         |
| Prozess bleibt gleich, Tool kommt dazu | Prozess wird für Kollaboration neu gedacht           |
| Qualität durch mehr Kontrolle          | Qualität durch klare Verantwortung                   |

---

## Das Kollaborations-Framework

### Drei Fragen für jeden Prozessschritt

1. **Wer initiiert?** (Mensch oder KI)
2. **Wer veredelt?** (Qualität, Kontext, Anpassung)
3. **Wer verantwortet?** (Freigabe, Haftung, Entscheidung)

---

## Typische Kollaborationsmuster

### Muster 1: KI-First (Entwurf → Veredelung)

```
KI erstellt ersten Entwurf
    → Mensch prüft und verfeinert
    → Mensch gibt frei
```

**Geeignet für:** Texterstellung, Recherche, Datenaufbereitung, Konzeptentwürfe

**Beispiel Marketing:**

- KI: Erstellt 3 Varianten einer Produktbeschreibung
- Mensch: Wählt beste Variante, passt Tonalität an, prüft Fakten
- Mensch: Gibt frei für Veröffentlichung

---

### Muster 2: Mensch-First (Vorgabe → Ausarbeitung)

```
Mensch definiert Rahmen/Briefing
    → KI arbeitet aus
    → Mensch prüft Ergebnis
```

**Geeignet für:** Komplexe Aufgaben mit spezifischen Anforderungen, kreative Arbeit mit klarer Vision

**Beispiel Vertrieb:**

- Mensch: Definiert Kundenbedürfnis und Angebotsrahmen
- KI: Erstellt passgenaues Angebot mit Textbausteinen
- Mensch: Prüft, personalisiert, versendet

---

### Muster 3: Ping-Pong (Iterative Verfeinerung)

```
Mensch gibt Input
    → KI antwortet
    → Mensch gibt Feedback
    → KI verbessert
    → (Wiederholung bis Ziel erreicht)
```

**Geeignet für:** Kreative Exploration, Problemlösung, komplexe Analysen

**Beispiel F&E:**

- Mensch: Beschreibt technisches Problem
- KI: Schlägt Lösungsansätze vor
- Mensch: "Ansatz 2 vertiefen, aber Kosten berücksichtigen"
- KI: Detailliert Ansatz 2 mit Kostenabschätzung

---

### Muster 4: Parallel (Mensch und KI gleichzeitig)

```
Mensch arbeitet an Aspekt A
    KI arbeitet an Aspekt B
        → Zusammenführung
        → Gemeinsame Finalisierung
```

**Geeignet für:** Zeitkritische Aufgaben, Aufgaben mit klar trennbaren Teilbereichen

**Beispiel Reporting:**

- Mensch: Schreibt Executive Summary und Empfehlungen
- KI: Aggregiert Daten, erstellt Visualisierungen
- Zusammenführung zu fertigem Report

---

## Prozess-Design: Checkliste

Bei der Gestaltung von Mensch-KI-Prozessen klären:

### Rollen

- [ ] Wer macht den ersten Entwurf?
- [ ] Wer trifft welche Entscheidungen?
- [ ] Wer hat Freigabe-Verantwortung?
- [ ] Wer haftet für das Ergebnis?

### Übergaben

- [ ] Wie werden Aufgaben an KI übergeben? (Prompt-Struktur)
- [ ] Wie werden KI-Outputs an Menschen übergeben? (Format, Kontext)
- [ ] Wie wird Feedback strukturiert?

### Qualität

- [ ] Welche Qualitätsstandards gelten für KI-Outputs?
- [ ] Welche Prüfschritte sind obligatorisch?
- [ ] Wann ist "gut genug" erreicht?

### Ausnahmen

- [ ] Wann wird vom Standard-Prozess abgewichen?
- [ ] Wie wird eskaliert wenn KI-Output unbrauchbar?
- [ ] Fallback wenn KI nicht verfügbar?

## Anwendungsbeispiel: Verlagswesen

### Vorher (sequentiell, rein menschlich)

1. Autor recherchiert (2 Tage)
2. Autor schreibt Entwurf (3 Tage)
3. Lektor prüft und korrigiert (1 Tag)
4. Autor überarbeitet (1 Tag)
5. Faktencheck (0,5 Tage)
6. Freigabe

**Gesamt: ~7,5 Tage**

### Nachher (Mensch-KI-Kollaboration)

1. Autor + KI: Recherche parallel (0,5 Tage)
2. KI erstellt strukturierten Entwurf nach Briefing (0,5 Tage)
3. Autor veredelt, bringt Expertise ein (1 Tag)
4. KI + Lektor: Parallel-Check (Grammatik KI, Stil Lektor) (0,5 Tage)
5. Autor finalisiert (0,5 Tage)
6. Faktencheck (Mensch, kritische Stellen) (0,5 Tage)
7. Freigabe

**Gesamt: ~3,5 Tage**

### Klare Verantwortlichkeiten

| Rolle        | Verantwortung                                            |
| ------------ | -------------------------------------------------------- |
| KI           | Recherche-Aggregation, Entwurfsstruktur, Grammatik-Check |
| Autor        | Fachexpertise, Stil, Einordnung, finale Qualität         |
| Lektor       | Stilistische Feinabstimmung, Lesbarkeit                  |
| Faktenprüfer | Korrektheit kritischer Aussagen                          |

## Häufige Fehler

| Fehler                            | Konsequenz                              | Besser                                      |
| --------------------------------- | --------------------------------------- | ------------------------------------------- |
| Keine klaren Verantwortlichkeiten | "Ich dachte, die KI hätte das geprüft"  | Explizit dokumentieren wer was verantwortet |
| KI-Output ohne Review             | Fehler, Halluzinationen, Peinlichkeiten | Immer menschliche Qualitätssicherung        |
| Zu viele Iterationen              | Zeitvorteil geht verloren               | Klares "Done"-Kriterium definieren          |
| KI für ungeeignete Aufgaben       | Frustration, schlechte Ergebnisse       | Muster bewusst wählen nach Aufgabentyp      |

---

## Tonspur für Präsentationen

- Kollaboration ist das Schlüsselwort – nicht Ersatz, nicht Tool
- Analogie: Wie die Einführung von E-Mail Kommunikationsprozesse verändert hat
- Die besten Ergebnisse entstehen, wenn Stärken kombiniert werden (KI: Geschwindigkeit, Breite / Mensch: Urteil, Kontext, Kreativität)
- Prozesse aktiv neu denken, nicht KI in alte Prozesse quetschen
