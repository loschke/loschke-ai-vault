# AI-Video-Use-Case-Social-Media

## Überblick

Social Media Video (TikTok, Reels, Shorts) ist der **volumenstärkste Use Case** für AI-Video. Kurze Produktionszyklen, hohe Frequenz und Platform-Algorithmen machen AI-Tools hier besonders wertvoll.

---

## Empfohlene Script-Strukturen

→ Ausführliche Beschreibungen: [[04_Pre-Production/Script-Strukturen|Script-Strukturen]]

| Struktur | Wann verwenden | Beispiel |
|----------|----------------|----------|
| **Micro-Dramatic Arc** | Storytelling in 15-30s | Hook → Konflikt → Klimax → Resolution |
| **Before/After** | Transformation zeigen | Tutorials, Makeovers, Product Demos |
| **PAS (verkürzt)** | Problem-Solution in 15s | Quick Tips, Life Hacks |
| **Q&A** | FAQ-Content, Educational | "Warum X?" → Erklärung |

**Social-Regel:** Hook in 3s, dann Struktur. Ohne Hook keine Views.

## Platform-Landschaft 2025

| Platform | User-Basis | Video-Länge | Besonderheit |
|----------|-----------|-------------|--------------|
| **TikTok** | 1B+ User | 3s - 10min | 50% kaufen nach TikTok-Content |
| **Instagram Reels** | 500M+ Daily Story User | 15-90s | Professional + Personal |
| **YouTube Shorts** | 2B+ Logged-in User/Mo | bis 60s | Discovery → Long-Form Funnel |
| **LinkedIn Video** | 1B+ Member | 3s - 10min | B2B, Thought Leadership |

**Key Insight:** Video = 80%+ des Internet-Traffics, Short-Form hat größten Engagement-Anteil.

## Algorithm-Verständnis 2025

### TikTok Algorithm (2025 Updates)

**Primäre Signale:**
1. **Watch Time** (nicht nur Completion) – Rehooks für längere Videos einbauen
2. **Saves & Shares** > Likes (stärkere Relevanz-Signale)
3. **Trial-and-Error:** Neue Videos → kleine Gruppe → Engagement bestimmt Rollout

**Wie der Algo arbeitet:**
```
Neues Video → 200-500 Views Test
     ↓
Engagement gut? → Nächste Audience-Stufe
     ↓
Wiederhole bis Video "stirbt" oder viral geht
```

### Instagram Reels Algorithm

**Ranking-Faktoren:**
1. User Activity (was interagiert der User normalerweise mit)
2. Interaction History (frühere Interaktion mit Creator)
3. Reel Information (Audio, Visuals, Popularität)
4. Creator Information (Engagement-History)

**Deprioritized:**
- TikTok-Wasserzeichen sichtbar
- Niedriger Auflösung/Audio
- Übermäßig salesy Content

## Platform-spezifische Best Practices

### TikTok

| Aspekt | Best Practice |
|--------|---------------|
| **Hook** | Erste 3 Sekunden entscheidend – visuell + Text |
| **Rehooks** | Bei längeren Videos: Multiple Hooks einbauen |
| **CTA** | Klar: "Swipe up", "Link in Bio", "Tap to Shop" |
| **Produkt** | In ersten Sekunden zeigen, nicht verstecken |
| **Captions/Sticker** | Discounts/Features highlighten |
| **Wasserzeichen** | Keine von konkurrierenden Apps |
| **Audio** | Trending Sounds nutzen (Discover-Page checken) |

### Instagram Reels

| Aspekt | Best Practice |
|--------|---------------|
| **Qualität** | High-Quality Video + Audio essentiell |
| **Länge** | Sweet Spot: 15-30s für max Completion |
| **Content** | Value first, nicht übermäßig salesy |
| **Konsistenz** | Regelmäßiges Posting baut Momentum |
| **Watermarks** | Keine sichtbaren TikTok-Logos |
| **Engagement** | Auf Comments antworten, Community bauen |
| **Original** | Eigener Content oder proper Credit |

### YouTube Shorts

| Aspekt | Best Practice |
|--------|---------------|
| **Hook** | Sofort in Action starten |
| **Loop** | Ende → Anfang nahtlos = Repeat Views |
| **Text** | On-screen Text für Sound-off Viewer |
| **Funnel** | CTA zu Long-Form Content |
| **Hashtags** | #Shorts immer inkludieren |

## Cross-Platform Strategy

### Content-Differenzierung

**NICHT:** Ein Video für alle Platforms erstellen

**SONDERN:**
```
Kern-Idee
    ├── TikTok: Casual, trending audio, native Captions
    ├── Reels: Polished, on-brand, high-quality
    ├── Shorts: Loopable, educational hooks
    └── LinkedIn: Professional angle, insights
```

### Repurposing-Workflow

```
Long-Form Content (YouTube, Podcast, Webinar)
          ↓
     AI-Clipping (Wave.Video, Captions.ai)
          ↓
     Platform-Native Anpassung
          ↓
     Scheduling (SocialBee, Buffer)
```

## AI-Disclosure Requirements 2025

### YouTube
- **Required für:** Realistic altered/synthetic content
- **Gilt für:** Synthetic Voices, manipulierte Visuals, fabricated Events
- **NICHT required:** Color Correction, Stylization, Animation
- **Wie:** Disclosure Toggle beim Upload

### Meta (Instagram/Facebook)
- **C2PA Metadata** Auto-Detection (Adobe Firefly, Shutterstock AI)
- **"AI Info"/"Made with AI"** Label automatisch
- **Manuelle Disclosure** required für non-C2PA Tools (Canva Pro, Runway)
- **Restyle AI Tool** in Reels mit automatischem Tagging

### TikTok
- Labeling Requirements in Evolution
- Fokus auf Transparenz für AI-generated Content
- AI Label bei offensichtlich generierten Inhalten

## Content-Optimierung

### Hook-Formeln die funktionieren

1. **Kontroverse:** "Everyone's doing X wrong..."
2. **Geheimnis:** "The thing no one tells you about..."
3. **Listen:** "3 reasons why..."
4. **How-To:** "Here's how to X in 30 seconds"
5. **Relatable:** "POV: You just..."
6. **Challenge:** "I tried X for 30 days..."

### Retention Tactics

| Taktik | Umsetzung |
|--------|-----------|
| **Pattern Interrupt** | Alle 3-5s visuelle Änderung |
| **Text Layering** | On-screen Text + Voice + Visuals |
| **Cliffhanger** | "Wait for it..." / "Watch until the end" |
| **Looping** | Ende führt nahtlos zu Anfang |
| **Fast Pacing** | Kein Moment ohne Information |

### Aspect Ratios

| Format | Ratio | Platforms |
|--------|-------|-----------|
| **Vertical** | 9:16 | TikTok, Reels, Shorts, Stories |
| **Square** | 1:1 | Instagram Feed, LinkedIn |
| **Horizontal** | 16:9 | YouTube, Website Embeds |

## Workflow: AI Social Video Production

### Schnell-Workflow (< 30 Min für 1 Video)

```
1. Idee/Hook formulieren (5 min)
        ↓
2. Script in AI (3 min) → Claude/GPT
        ↓
3. Video generieren (10 min) → Zebracat/Invideo
        ↓
4. Captions + Musik (5 min) → CapCut
        ↓
5. Export + Post (5 min)
```

### Batch-Workflow (Content für 1 Woche)

```
Tag 1: Ideation
   - 10 Ideen brainstormen
   - Hooks schreiben
   
Tag 2: Production
   - 7 Videos generieren
   - Batch-Processing in AI Tools
   
Tag 3: Optimization
   - Captions finalisieren
   - Thumbnails erstellen
   - Scheduling
```

## Checkliste: Social Video erstellen

### Pre-Production
- [ ] Hook in ersten 3 Sekunden
- [ ] Klarer Value für Viewer
- [ ] Platform-spezifisches Format (9:16, 1:1, etc.)

### Production
- [ ] High-Quality Audio (kein Background Noise)
- [ ] Captions/Subtitles eingebaut
- [ ] Trending Audio berücksichtigt (wenn passend)

### Post-Production
- [ ] Keine Wasserzeichen anderer Platforms
- [ ] AI-Disclosure wenn nötig
- [ ] Thumbnail/Cover optimiert

### Publishing
- [ ] Relevante Hashtags
- [ ] Engaging Caption
- [ ] CTA klar
- [ ] Optimal Timing (Platform-spezifisch)
