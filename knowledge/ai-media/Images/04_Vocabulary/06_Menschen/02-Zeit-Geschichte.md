# Zeit & Geschichte – Token-Referenz

Tokens für historische Epochen, Jahrzehnte und Zukunftsszenarien.

---

## Zivilisationen & Imperien

Historische Figuren aus vergangenen Hochkulturen.

| Token | Epoche |
|-------|--------|
| `Ancient Egypt` | Altes Ägypten |
| `Ancient Greece` | Antikes Griechenland |
| `Roman Empire` | Römisches Reich |
| `Byzantine Empire` | Byzantinisches Reich |
| `Mesopotamia` | Mesopotamien |
| `Viking figure` | Wikingerzeit |
| `Medieval Knight` | Mittelalter |
| `Aztec civilization` | Azteken |
| `Maurya Empire` | Indisches Maurya-Reich |
| `Chinese Empire` | Kaiserliches China |

**Beispiel-Prompt:**
```
A portrait of a historical figure from Ancient Greece in traditional attire, set against a backdrop that evokes the era –style raw
```

> **Hinweis zu Halluzinationen:** Bei historischen Motiven generiert die KI oft illustrative Stile (basierend auf Trainingsdaten). Fotorealistische Ergebnisse stammen häufig aus Film-/Serien-Material. Details wie Kleidung oder Farben können historisch unkorrekt sein.

## Jahrzehnte (1880–2020)

Jahreszahlen im Prompt reproduzieren den visuellen Zeitgeist.

| Dekade | Typische Merkmale |
|--------|-------------------|
| `1880s` | Viktorianisch, frühe Fotografie |
| `1890s` | Spätes 19. Jahrhundert |
| `1900s` | Jahrhundertwende |
| `1910s` | Edwardianisch, WWI |
| `1920s` | Roaring Twenties, Art Deco |
| `1930s` | Depression, Hollywood Golden Age |
| `1940s` | WWII, Swing-Ära |
| `1950s` | Nachkriegs-Optimismus, Rock'n'Roll |
| `1960s` | Mod, Hippie-Bewegung |
| `1970s` | Disco, Earthtones |
| `1980s` | Neon, Schulterpolster |
| `1990s` | Grunge, Minimalismus |
| `2000s` | Y2K, frühe Digitalästhetik |
| `2010s` | Instagram-Ära, Hipster |
| `2020s` | Gegenwart |

**Tipp:** Jahreszahl am Anfang UND Ende des Prompts verstärkt die Authentizität.

### Szenarien

**Stadtszene:**
```
1960s photo of a 30-year-old well-dressed man standing next to his parked vehicle in a german city, taken in 1960 –style raw
```

**Wohnszene:**
```
1950s photo of a 30-year-old well-dressed woman sitting on a couch in a german living room, taken in 1950 –style raw
```

**Alltagsgegenstände:**
```
a typical 1970s phone –style raw
```

> **Hinweis:** Alltagsgegenstände werden passend reproduziert. Bei weniger Trainingsdaten kann es zu Halluzinationen kommen (z.B. iPhone als Standard für "modernes Telefon").

## Zukunft

Fiktive Zukunftsszenarien mit `futuristic` + Jahreszahl.

| Zeitraum | Stil |
|----------|------|
| `year 2100` | Nahe Zukunft, erkennbar |
| `year 2200` | Mittlere Zukunft |
| `year 3000` | Ferne Zukunft, stark verändert |

**Beispiel-Prompts:**

**Stadt & Verkehr:**
```
year 2200, photo of a man standing next to his futuristic vehicle in a futuristic city, taken in the year 2200
```

**Wohnen:**
```
year 3000, futuristic photo of a woman sitting in a futuristic living room, taken in the year 3000
```

**Technologie:**
```
concept of a futuristic phone in the year 3000
```
