# Foto-Stile – Token-Referenz

Tokens für fotografische Genres und Stilrichtungen. Definiert die *Art* des Fotos.

---

## Menschen & Urban

| Token | Charakter |
|-------|-----------|
| `fashion photo` | Mode-Fotografie, stylisch, inszeniert |
| `street style photo` | Authentisch, urban, Alltags-Mode |
| `editorial photo` | Magazin-Look, konzeptionell |
| `documentary photo` | Reportage, ungestellt, erzählend |
| `historical photo` | Zeitdokument-Anmutung |
| `lo-fi photo` | Low-Fidelity, casual, unperfekt |
| `cinematic still` | Filmszenen-Ästhetik |
| `minimalist photo` | Reduziert, klare Komposition |

**Beispiel-Prompt:**
```
street style photo of a young woman in Tokyo, autumn fashion
```

---

## Tiere & Natur

| Token | Charakter |
|-------|-----------|
| `wildlife photo` | Tierfotografie, natürlicher Lebensraum |
| `national geographic photo` | Magazin-Qualität, episch, professionell |
| `documentary photo` | Verhaltens-Dokumentation |
| `minimalist photo` | Tier isoliert, cleaner Hintergrund |

**Beispiel-Prompt:**
```
national geographic photo of a snow leopard in the Himalayas
```

---

## Architektur

| Token | Charakter |
|-------|-----------|
| `architectural photo` | Gebäude-Fokus, Linien, Strukturen |
| `historical photo` | Historische Anmutung |
| `minimalist photo` | Reduzierte Komposition |
| `lo-fi photo` | Casual, Schnappschuss-Charakter |

**Beispiel-Prompt:**
```
architectural photo of a brutalist museum, dramatic sky
```

---

## Produkt

| Token | Charakter |
|-------|-----------|
| `product photo` | Kommerziell, sauber, verkaufsorientiert |
| `fashion photo` | Mode-Kontext, Lifestyle |
| `editorial photo` | Magazin-Inszenierung |
| `minimalist photo` | Produkt isoliert, cleaner Look |

**Beispiel-Prompt:**
```
minimalist product photo of a perfume bottle, soft shadows
```

---

## Kombinations-Hinweise

Stil-Tokens stehen typischerweise am Anfang:

```
[STIL] photo of [MOTIV], [WEITERE DETAILS]
```

Können mit Perspektive und Technik kombiniert werden:

```
editorial photo, three-quarter view, Kodak Portra 400 film, portrait of a model in a greenhouse
```
