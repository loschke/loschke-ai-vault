# Perspektive – Token-Referenz

Tokens für Blickrichtung, Bildausschnitt und Kamerawinkel.

---

## Blickrichtung

Aus welcher Richtung schaue ich auf das Motiv?

| Token | Wirkung |
|-------|---------|
| `frontal shot` | Direkt von vorn – Offenheit, Konfrontation |
| `side view` | Profil – Charakter, Eleganz |
| `rear view` | Von hinten – Anonymität, Bewegungsrichtung |
| `three-quarter view` | Klassiker – Tiefe, Dynamik |
| `back three-quarter view` | Schräg von hinten – Kontext zeigen |
| `bottom-up view` | Von unten – Macht, Größe |
| `aerial view` | Von oben – Übersicht, Verletzlichkeit |
| `overhead shot` | Direkt von oben – Muster, Anordnung |

**Hinweis:** Funktioniert für Personen, Tiere und Objekte gleichermaßen.

---

## Bildausschnitt

Wie viel vom Motiv ist sichtbar?

| Token | Zeigt | Typischer Einsatz |
|-------|-------|-------------------|
| `extreme close-up shot` | Detail (Auge, Hand) | Emotion, Textur |
| `close-up shot` | Gesicht | Porträt, Ausdruck |
| `medium close-up shot` | Kopf bis Brust | Interview-Look |
| `medium shot` | Hüfte aufwärts | Gespräch, Gestik |
| `cowboy shot` | Oberschenkel aufwärts | Action, Western-Klassiker |
| `full-body shot` | Ganze Person | Kleidung, Pose, Kontext |
| `wide shot` | Person + viel Umgebung | Establishing, Landschaft |

---

## Kamerawinkel

Aus welcher Höhe fotografiere ich?

| Token | Wirkung |
|-------|---------|
| `eye-level` | Neutral – auf Augenhöhe |
| `low-angle` | Froschperspektive – Macht, Imposanz |
| `extreme low-angle` | Stark von unten – Dramatik |
| `high-angle` | Von oben herab – Verletzlichkeit |
| `bird's eye view` | Vogelperspektive – Übersicht |
| `drone shot` | Luftaufnahme – modern, cinematic |
| `ground-level view` | Bodennah – Tier-/Kinderperspektive |
| `dutch angle` | Gekippt – Spannung, Unruhe |

---

## Spezielle Perspektiven

| Token | Effekt |
|-------|--------|
| `over-the-shoulder` | Blick über Schulter – Dialog, Gaming |
| `selfie perspective` | Handy-Selfie-Look |
| `POV shot` | Subjektive Kamera – "durch meine Augen" |
| `worm's eye view` | Extrem bodennah |

---

## Kombinationen

Tokens lassen sich kombinieren:

```
low-angle three-quarter view, full-body shot, photo of...
```

**Reihenfolge:** Winkel → Richtung → Ausschnitt → Motiv
