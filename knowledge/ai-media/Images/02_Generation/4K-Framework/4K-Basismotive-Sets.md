# 4K Basismotive – Sets für den Unterricht

> 7 Sets à 4 Basismotive (Person, Tier, Objekt, Landschaft) für 4K-Framework-Seminare. Jedes Set mit Einzel-Prompts, Progressions-Prompts (durch alle Dimensionen) und Kombinations-Prompts.

## Konzept

Teilnehmer wählen ein Set (oder definieren eigene Motive) und arbeiten den ganzen Seminartag damit. Durch die wiederkehrenden Motive wird der Lernfortschritt durch die 4K-Dimensionen sichtbar.

### Ablauf
1. Einzelbilder generieren (nur Konzept)
2. Eine Person durch alle Dimensionen führen (Live-Demo)
3. Teilnehmer fügen eigene Dimensionen hinzu
4. Kombinationen als Abschluss (2er → 3er → 4er)

## Set-Empfehlung nach Seminar-Typ
- **Einsteiger/Gemischt:** Set 0 (Demo) + Set 1, 3, 4
- **Kreativ/Agentur:** Set 4, 5, 6
- **Business/Konzern:** Set 2, 3
- **Inhouse Produkt:** Set 0 (Demo) + eigene Firmenbezug-Motive
