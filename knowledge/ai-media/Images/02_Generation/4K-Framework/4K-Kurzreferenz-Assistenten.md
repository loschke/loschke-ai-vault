# 4K Framework – Kurzreferenz für Chat-Assistenten

> Portables Kontextdokument: In jeden Chat-Assistenten (Claude, Gemini, ChatGPT) einfügbar. Macht den Assistenten zum 4K-kompetenten Bild-Prompt-Generator.

## Zweck

Der Nutzer fügt dieses Dokument als Kontext in einen Chat ein. Danach kann er einfach sagen „Erstelle mir Prompts für X" und der Assistent wendet automatisch das 4K Framework an – unabhängig vom Modell.

## Inhalt

- 4K Framework komplett (alle 4 Dimensionen mit Vokabular)
- 7 Regeln für Prompt-Erstellung
- Ausgabeformat-Spezifikation (Einzel, Varianten, Serie)
- Prompt-Formel-Logik für Serien
- Qualitätscheckliste (intern für den Assistenten)
- Beispiel-Interaktion mit Aufschlüsselung
